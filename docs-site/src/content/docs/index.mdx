**Actual Bench** is an independent companion app for Actual Budget. Use it for bulk data management,
full-year planning, statement reconciliation, budget-file sync, diagnostics, and scheduled work.

Use Actual Budget for day-to-day transaction entry, routine budgeting, reports, and bank connections.

:::note[Independent companion app]
This is not the official Actual Budget app, and not its documentation. It points at an Actual Server
you already run.
:::

![Actual Bench showing twelve months of a budget at once, with the details panel open beside it.](../../assets/screenshots/user-guide/budget-envelope.png)

## Start from what you need to do

| I want to… | Actual Bench provides | Go to |
|---|---|---|
| Plan a full year, not six months | A 12-month Budget, Actuals, or Balance grid with spreadsheet-style editing | [Budget](user-guide/budget-management/) |
| Seed a budget from a spreadsheet, or clean one up in bulk | Bulk creation, merge, import, export, dependency checks, and staged review for budget records | [Editing, review and save](getting-started/editing-and-saving/) |
| Fix the duplicate payees my bank imports keep creating | Suggested duplicate groups, merge impact, and optional rules to prevent new duplicates | [Payee Cleanup](user-guide/payee-cleanup/) |
| Write better rules, and audit the ones I have | Rule authoring, templates, formulas, CSV, and diagnostics for broken, overlapping, broad, or duplicate rules | [Rules](user-guide/rules/) · [Rule Diagnostics](user-guide/rule-diagnostics/) |
| Reconcile an account against a bank statement | A persistent statement comparison with reviewed create, update, and delete actions | [Bank Reconciliation](user-guide/bank-reconciliation/) |
| Copy data between two budget files, in two currencies | One-way transaction, payee, and category flows with mappings, review queues, history, and optional FX conversion | [Budget File Sync](user-guide/budget-sync/) |
| Pull in new transactions without opening anything | Scheduled Actual bank syncs with a result for each linked account; Actual keeps the bank connection | [Bank Sync](user-guide/bank-sync/) |
| Have work run on a timetable while the app is closed | Scheduled bank syncs, backups, and safe syncs with run history, health, backoff, and credentials for HTTP API mode | [Automations](user-guide/automations/) |
| Create verified backups | Scheduled copies to folders or S3-compatible storage, verification, retention protection, and recovery information | [Backups](user-guide/backups/) |
| Ask a question of my data that no screen answers | Read-only ActualQL queries, exported-file diagnostics, and SQLite inspection | [ActualQL Queries](user-guide/actualql/) |
| Find out whether a budget file is sound | Structural checks and file metadata over an exported snapshot | [Budget File Health](user-guide/budget-file-health/) |
| Move a whole budget structure somewhere else | A ZIP of accounts, payees, categories, tags, schedules, and rules, imported in dependency order | [Bundle Export / Import](getting-started/bundle-export-import/) |

The sidebar follows the app's navigation. Use it when you know the workspace you need.

Manual budget changes remain available for review until you confirm them. See
[Work safely](getting-started/core-concepts/) for the rule and its exceptions.

Actual Budget remains the place for day-to-day transaction entry, routine budgeting, reports, mobile
use, and bank connections. Actual Bench schedules Actual's existing bank sync and reports its result;
it does not connect to a bank itself. [What Actual Bench adds](getting-started/introduction/) explains
the boundary in more detail.
