This page collects the limits that cut across features, with a way around each where there is one.
Limits that belong to one feature are listed on its own page. This page does not describe planned
work.

## Scope

- **Desktop browsers.** Actual Bench is built for a laptop or desktop screen. Use Actual itself on
  your phone.
- **Day-to-day entry stays in Actual.** Bench reads what you record; it is not a place to enter
  everyday transactions.
- **One currency per budget file**, as in Actual. Use [Cross Budget Sync](../../user-guide/budget-sync/)
  with [Exchange Rates](../../user-guide/fx-rates/) to bring a second currency together.

## Actual Server versions

- **Tags** need Actual Budget 26.3.0 or later.
- **Account groups** need Actual Budget 26.9.0 or later, and cannot be reordered from Bench because
  Actual's API offers no way to do it.

## Rules set by Actual

- An account's **on-budget / off-budget** placement is fixed when it is created.
- **Transfer payees** and the rules that belong to **schedules** are managed by Actual, so they are
  read-only in Bench.
- **Income categories** stay in the income group.

## Connections and credentials

- **A forgotten Actual Bench password cannot be recovered.** Setting a new one with
  `ACTUAL_BENCH_PASSWORD` clears remembered budgets, so you connect them again. Automations and
  backups are kept.
- **Remembered budgets belong to one Bench install.** They are not shared between installs, and
  only survive restarts when `/data` is kept.
- **Enrolling the first budget on a server needs a live connection to it,** because that is when
  the browser holds its password. The server's other budgets can then be enrolled without
  connecting to each.
- **ActualQL's cURL export** is only offered in HTTP API mode.

## Running Bench

- **One instance.** The automation scheduler runs inside the server and does not coordinate between
  several copies of Bench on one database.
- **Large budget snapshots** in Budget File Health and the Data Browser are opened in your browser,
  so a very large file is limited by its memory.
- **Very long category lists** scroll slowly in Budget Cockpit.

## Asking for more

If a limit is in your way, open a feature request on
[GitHub](https://github.com/x-rous/actual-bench/issues) describing what you are trying to do.
